# About Gilead 311 (synthetic)

Gilead 311 takes non-emergency requests for City services. For fires, gas smells, downed power lines, crashes with injuries, or a crime in progress, call 911.

The online assistant can take requests for: damaged or missing bins, missed collection, dead animals on public property, injured or distressed animals, potholes and road damage, tree problems, property standards, and illegal dumping on public land.

The assistant can also check the status of an existing request. You need the request number (it looks like 311-2026-000123) and the postal code of the address on the request.

Each request gets a number when it is created. Keep this number to check the status later. The assistant cannot change, cancel or speed up a request.

To speak with a person, call 311 or ask the assistant to pass your request to a 311 staff member.
